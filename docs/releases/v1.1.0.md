# CodeNest v1.1.0

## Highlights

- Improved project scanning with richer Git source metadata, language overrides, and more reliable import behavior.
- Added editor visibility controls so unused launch targets can be hidden throughout the app.
- Refined project titles and editor command inputs for a cleaner, more consistent workflow.
- Added a reusable **Open With** menu to both project list rows and project cards.

## Quality and delivery

- Expanded high-value frontend and Rust test coverage for scanners, WebDAV, editor settings, and project actions.
- Added provenance attestations for CI and release artifacts.
- Updated the JavaScript, Rust, and GitHub Actions dependency sets.
- Resolved the reported dependency vulnerabilities in PostCSS, Immutable.js, SVGO, and brace-expansion.

## Compatibility

- No user data migration is required when upgrading from v1.0.1.
- TypeScript remains on the latest compatible 6.x release until the ESLint toolchain supports TypeScript 7.
